# Vasquez Single Cell Analysis

This repository contains the analyses performed for the research work by Daniel Vasquez et al.

## Overview

The project focuses on single-cell analysis to uncover insights into cellular heterogeneity and gene expression patterns. The analyses include data preprocessing, clustering, differential expression analysis, and visualization of results.

## Analyses Performed

1. **Data Preprocessing**  
    - Quality control and normalization of single-cell RNA sequencing data.

2. **Clustering**  
    - Identification of cell populations using clustering algorithms.

3. **Differential Expression Analysis**  
    - Detection of genes with significant expression differences across clusters.

4. **Visualization**  
    - Generation of plots and heatmaps to illustrate findings.
